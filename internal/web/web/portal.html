Core Capabilities

        
专为商业大模型研发的企业级网关

        

          攻克复杂 WebSocket 私有链路，赋予微软 Copilot 商业账户开放、标准、极速的调用生命力。
        

      


      

        
        

          

            
          

          
ChatHub 协议层深度封装

          

            内部完整封装 M365 Copilot ChatHub 的握手交互、心跳保活和复杂的 JSON 消息解析，对外提供标准 SSE 实时逐字流式打字效果。
          

        


        
        

          

            
          

          
内容键会话增量复用

          

            独创类似上下文缓存机制：以对话历史内容为键稳定复用云端已有对话，命中时仅发送最新增量消息，大幅节省传输开销与请求延迟。
          

        


        
        

          

            
          

          
多商业账号池与自动容灾

          

            支持一键 OAuth / PKCE 商业账号授权绑定，支持多账号并发控制、健康状态探测与账号故障时的毫秒级无缝自动转移。
          

        


        
        

          

            
          

          
双向 Function Calling 工具调用

          

            完美兼容标准 OpenAI Function Calling 协议，智能双向翻译为 M365 工具规划链路，支持 Cursor、Claude Code 自主执行终端工具。
          

        


        
        

          

            
          

          
全模态图片解析与创意绘制

          

            支持用户输入多张图片附件（Base64 或 URL），自动完成微软底层上传注入；同时支持 `/v1/images/generations` 进行高质量图像生成。
          

        


        
        

          

            
          

          
纯净自托管与本地隐私沙箱

          

            支持 Docker 一键自建，所有 Token、会话和 API Key 均存储在本地（支持 DPAPI/AES 加密），不经过任何第三方公网服务器。
          

        

      

    


    
    

      

        
Architecture Topology

          客户端标准请求进入网关，智能解析会话与账号池，经由高保活 WebSocket 链路直通微软云端集群。
